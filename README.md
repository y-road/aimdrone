# AimDrone

해 질 녘 들판의 방어 진지에서, 웨이브로 몰려오는 공격 드론을 소총으로 격추하는 1인칭 웹 슈팅 게임입니다. 설치 없이 브라우저에서 바로 플레이합니다.

## 게임 소개
- **무대:** 모래주머니로 둘러싼 대공 초소. 노을 진 하늘에 서치라이트와 예광탄이 오가고, 드론이 웨이브 단위로 날아옵니다.
- **목표:** 드론이 진지에 닿기 전에 떨어뜨려 점수를 올리고, 최대한 오래 버팁니다.
- **무기:** AKM 소총과 도트 사이트. 탄창 30발, 예비탄 360발(다 쓰면 다시 보급).

## 적
| 드론 | 특징 |
|---|---|
| 샤헤드형 자폭 드론 | 높은 고도로 접근한 뒤 플레이어 위치로 급강하합니다. 충돌 직전에는 방향을 바꾸지 못합니다. 3발에 격추되며, 불붙은 채 추락해 폭발합니다. |
| FPV 드론 | 작고 빠르며 좌우로 흔들면서 플레이어에게 돌진합니다. 가까워지면 직선으로만 날아와 옆으로 피할 수 있습니다. 1발에 격추됩니다. |

웨이브가 올라갈수록 수가 늘고 빨라집니다.

## 점수
- 명중할 때마다 점수, 격추하면 큰 점수
- 멀리서 격추할수록 거리 보너스
- 연속 격추 시 배수(STREAK)
- 웨이브를 막아내면 클리어 보너스와 체력 회복

드론이 터지면 체력이 깎이고, 0이 되면 게임이 끝납니다. 피해는 폭발 지점과의 거리에 따라 달라집니다. 몸에 직접 맞으면 최대 피해, 멀어질수록 줄어들고 충분히 멀면 피해가 없습니다. 화면에 INCOMING 경고가 뜨면 움직여서 폭발 지점에서 벗어나세요.

## 조작
| 입력 | 동작 |
|---|---|
| 마우스 | 시점 |
| 좌클릭 | 사격 |
| 우클릭 | 조준 전환 (한 번 더 누르면 해제) |
| W A S D | 이동 (진지 안팎을 오갈 수 있음) |
| Shift | 달리기 |
| Space | 점프 |
| Ctrl 또는 C | 앉기 |
| R | 재장전 |
| Esc / P | 일시정지, 감도 설정 |

모바일에서는 화면을 끌어 조준하고, 화면의 FIRE · AIM · RLD 버튼을 사용합니다.

## 랭킹
게임이 끝나면 이름을 넣어 점수를 등록할 수 있습니다. 전체 상위 100위와 내 순위가 표시되며, 시작 화면의 Ranking 버튼으로도 볼 수 있습니다.
